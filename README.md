# Thrustbound: Vertical Rise - Privacy Policy

This repository hosts the official Privacy Policy for the Android mobile game **Thrustbound: Vertical Rise** (`com.mouse.verticalrise`) developed and published by **Green Mouse**.

### Web URL (Google Play Privacy Policy)
The privacy policy is published via GitHub Pages at:
- [https://dziher11.github.io/VerticalRise/](https://dziher11.github.io/VerticalRise/)

---

### Key Privacy Highlights
- **Zero Data Collection:** The game does not collect, transmit, store, sell, or share any personal data, location data, or device identifiers.
- **100% Offline Operation:** All gameplay, graphics, sounds, and music run entirely offline with zero network requests.
- **Zero Sensitive Permissions:** No access to camera, microphone, contacts, location, or external storage.
- **Device Sensors:** Accelerometer / Tilt sensor is used purely for real-time player steering in volatile memory, never stored or transmitted.
- **No Advertisements or Trackers:** 100% free of ads, analytics, or third-party SDKs.
- **Child-Safe & Family-Friendly:** Fully compliant with Google Play Families Policy, COPPA, and GDPR-K.
